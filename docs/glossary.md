# Glossary

| Term | Definition |
|------|------------|
| **Pillar** | One of four dimensions of a whole person (`P1`–`P4`); the top of the traceability chain under the vision. |
| **Domain** | A broad content area (`D01`–`D10`), anchored to a pillar. |
| **Strand** | A persistent thread within a domain (`Dxx.Sn`) that spirals across grades. |
| **Standard / Objective** | A grade-level, measurable expectation (`Dxx.Sn.<grade>.<n>`). |
| **Unit** | A coherent multi-lesson block (`U.gg.nnn`). |
| **Lesson** | One day of instruction (`L.gg.nnn.nn`). |
| **Scope** | A grade's year plan (≈180 days) mapping units to days and domains. |
| **Traceability chain** | `Vision → Pillar → Domain → Strand → Standard → Unit → Lesson`. |
| **Cross-cutting lens** | A values lens (ethics, egalitarianism, global, technology, environment, …) applied to all content. |
| **Spiral** | The practice of revisiting concepts at increasing depth across grades. |
| **Enacted curriculum** | The units and lessons (`curriculum/k-12/`) that deliver the standards. |
| **Backlog** | The tracked list of work items the agent loop consumes. |
| **Agent loop** | The stateful process by which curriculum agents claim, author, and complete work. |
