# K–12 Enacted Curriculum

The day-to-day curriculum: grade-level scopes, units, and lessons.

## Layout

```
k-12/
└── grade-00-kindergarten/
    ├── README.md
    ├── scope.md                       # the year plan (~180 days)
    └── units/
        └── unit-001-who-am-i/
            ├── unit.md
            └── lessons/
                └── lesson-001-naming-feelings.md
```

## Grade directory naming

`grade-<gg>-<slug>` where `gg` is zero-padded (`00` = Kindergarten, `01`–`12`).
