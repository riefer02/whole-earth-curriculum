# Lesson 13 — Making a Picture Graph

## Summary

Learners ask a real question, collect answers from the whole group, and build a
**picture graph** — one object or mark for each answer, arranged in rows. Then they
read what it shows: which answer has the **most**, which the **fewest**, and how many
each, turning many small voices into one picture everyone can agree on.

## Objectives

- Collect and organize data into a simple chart or picture graph and answer
  questions about what it shows. _(D05.S4.01.01)_

## Connection

A village elder wants to know which crop the farmers planted most so the storehouse
can prepare; a family wants to know which meal everyone likes best; a teacher wants
to know how each child comes to school. When you ask everyone the same question and
put one mark for each answer in a row, you make a **picture graph** — and suddenly
the answer is easy to see. Turning voices into a picture is how people make decisions
together, fairly.

## Materials

- A simple survey question and a way to record answers
- One small picture, mark, seed, or stone per learner
- A large chart surface (paper, cloth, or the ground)

## Preparation

- Choose one question everyone can answer (a favorite fruit, how we get to school, a
  pet at home).
- Prepare a chart with one row for each possible answer.
- Give each learner one object or mark to place.

## Facilitator note

This lesson is written to the learner ("you"). It spirals up from Kindergarten's
"sort into groups" to **collecting data and building a picture graph** — the new
skill. Teach with a **worked example** (philosophy §13): ask the question, place the
first few objects in rows together, then let each learner add theirs. The powerful
ideas are **one object per answer** and **reading the graph** — most, fewest, and how
many. Frame the graph as a fair way to hear everyone: each person's answer counts
once, and no answer is more important than another (egalitarianism). Choose a
question that is respectful and has no "right" answer. For learners who are Deaf or
hard of hearing, pose the question in sign or pictures and let learners place their
object; for learners who are blind or low-vision, build a *tactile* graph — objects
in rows the hands can count. A learner who does not speak places their object or
points to their answer. Every answer is one mark, and every mark matters equally.

## Procedure

1. **Gather — a question for everyone (5 min).** Today we ask one question of
   everyone and turn the answers into a picture. Here is our question: ___ (for
   example, "Which fruit do you like best?").
2. **Worked example — place the first marks (10 min).** Watch and help: the chart has
   a row for each answer. The first few learners place one object in their answer's
   row. Notice: **one object for one person** — that is the rule that keeps the graph
   fair.
3. **Collect everyone's answer (10 min).** Each learner places one object in the row
   for their answer. When everyone has placed theirs, the graph is complete. Look at
   it: each row is a pile you can count.
4. **Read the graph (10 min).** Count each row. Which answer has the **most**? Which
   has the **fewest**? How many people chose each one? Are any rows the **same**
   number? Answer the question together.
5. **Ask new questions (7 min).** What else can the graph tell us? How many people
   answered in all? How many more chose the top answer than the bottom one? Wonder
   about it together.
6. **Close (3 min).** You asked a question, collected answers, and made a picture
   everyone could read. Data is just people's answers, made fair and clear — one mark
   for each voice.

## Differentiation

- **Support:** Use only two answer choices and count the rows together, touching each
  object.
- **Support (blind/low-vision):** Build the graph with objects in rows and read it by
  feeling and counting each row.
- **Extension:** Draw the picture graph on paper with one drawn mark per answer, and
  write a sentence about what the graph shows.

## Assessment

- **Formative (observation):** Can the learner place one object per answer to build a
  picture graph and answer questions about which has the most, the fewest, and how
  many?
- **Artifact (portfolio):** The completed picture graph (or a drawing of it), kept as
  a record of the learner's data work.

## Home connection

At home, ask everyone the same question ("which color do you like best?"), put one
mark or object for each answer in a row, and tell a grown-up which row has the most.
