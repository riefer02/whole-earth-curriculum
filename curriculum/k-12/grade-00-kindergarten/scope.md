# Kindergarten Scope

This is an **exemplar** scope. The `units:` list is illustrative — the full 180-day
plan (all units across all domains) is authored by the Scope Sequencer agent in
Phase 2.

## How to read this scope

Each `unit_id` resolves to a unit file under `units/`. `start_day`/`end_day` map the
unit onto the 180-day year. `domain_weighting` expresses the intended balance of
instructional time across domains.
